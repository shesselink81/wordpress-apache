# wordpress-images

Custom wordpress Docker images

Docker Compose apache example:
```console
git clone https://github.com/shesselink81/wordpress-apache.git
cd wordpress-apache
docker compose up -d
```
Docker Compose alpine example:
```console
git clone https://github.com/shesselink81/wordpress-apache.git
cd wordpress-apache/wordpress-alpine
docker compose up -d
```
